# 🎓 Student Grade Calculator

A school-level Student Grade Calculator developed using **C programming** and **Python Streamlit**.

The project started as a C programming project for calculating student marks, percentage, and grades. A Streamlit-based web interface was then created to make the calculator easier to use.

---

## 📌 Project Overview

The application allows the user to enter student information and marks for six subjects.

It calculates:

- Total Marks
- Percentage
- Grade
- Performance Remark

### Subjects

- Mathematics
- Science
- Marathi
- Hindi
- English
- Social Studies

Each subject is evaluated out of 100 marks.

---

## 📊 Grading System

| Percentage | Grade | Remark |
|------------|-------|--------|
| 90–100% | O | Outstanding |
| 80–89% | A+ | Excellent |
| 70–79% | A | Very Good |
| 60–69% | B+ | Good |
| 50–59% | B | Satisfactory |
| 40–49% | C | Pass |
| Below 40% | F | Needs Improvement |
